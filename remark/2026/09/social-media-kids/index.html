スマホや SNS は子どもを壊さない

Tags: #censorship #communication #internet #law #politics #privacy #risk #security
 :        
History in GitHub Page

（今回もタイトルは釣りです）

今回の記事は，八田真行さんの以下の記事を起点にしよう。

  • オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界（八田真行） - エキスパート - Yahoo!ニュース

特定のサイトやサービスに対して年齢制限を課す政治要求は昔から根強いが，上手くいったという話は聞いたことがない。 そもそも「子どものため」に SNS に年齢制限を課すという言い分は本当に妥当なのだろうか。 みんな「子どものため」というお題目のせいで思考停止しているのではないのか？

この『不安の世代（The Anxious Generation）』は yomoyomo さんのブログ記事にも時々登場するので（読んではいないが）名前は知っていたけど，よくあるニセ科学（pseudo-science）の類だろうとスルーしていた。 だって展開が「水からの伝言」や「ゲーム脳」と同じなんだもん。

ところが海外ではそうでもないらしい。

（邦訳版『不安の世代』は WirelessWire のブログ記事が出た後に刊行された）

うわぁ。 トンデモがカルトに発展する典型的なパターンだよ。 ぶっちゃけ「不安の世代」とは子どもではなく（トンデモに踊らされる）今の大人世代なんじゃないのか？

しかも政治家や為政者が（おそらく票集めのために）これに便乗するという最悪のケース。 カルトや哲学との癒着による動員は政治家の最も得意とするところだからね。 ナチスドイツ時代のヒトラーもやってたし。

八田真行さんは SNS を巡る危険や脅威についての議論を2つに分けるべきだと主張する。

デジタル技術の利用によるインパクトはじゃがいも程度らしい（笑）

要するに「子どもの心の健康をむしばむ」悪い大人やサービスのダークパターンは野放しで，被害を受ける子ども側をパージするという本末転倒なことをやっている（やろうとしている）わけだ。 現代においても子どもは人間社会におけるマイノリティで，公衆空間の周辺（もしくは外側）に置かれる（置かれようとする）存在なのである。

その結果どうなったか。 記事ではオーストラリアの事例を紹介している。

（今は知らないが）大昔のアダルトサイトの年齢確認では「未成年」を選択するとキッズ向けサイトにリダイレクトするという牧歌的な仕組みだった。 いずれにせよ，バカ正直に申告して期待する結果を得られないのなら迂回するに決まっている。 「インターネットは検閲をダメージであると解釈し，それを回避する」というやつだ。

これだけ見ても「子どものため」という旗を掲げる連中は，実は子どものことなど1ミリも考えてないということが分かるだろう。

八田真行さんの記事の主題である「技術的・法的・社会的限界」については，記事のほうを参照していただきたい（全部書くと元記事の丸写しになるのでw）。 記事では欧州や日本の状況も紹介されている。

個人的に気になっているのは「年齢確認」をサービスに組み込むことでセキュリティ・リスクを呼び込む点である。

ではどうすればいいのか。 八田真行さんは「国家が子どもを一律にネットから締め出すのではなく」「プラットフォームに「安全な設計」を義務付ける」「端末（OS）で、必要最小限の年齢情報だけを扱う」「家庭・学校・行政がそれぞれの役割を果たす」と提言されている。

人間社会の問題，特に人間関係の問題であれば，それを解決できるのは人間だけである。 そのための建付けとしてソフトウェア技術を用いるのであれば（ソフトウェアエンジニアの端くれとして）歓迎すべきことだが，それ自体が問題を解決するわけではないという点は頭に入れておくべきだろう。
